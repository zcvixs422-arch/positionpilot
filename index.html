☁️ Worker接続設定

Cloudflare Workerと接続して、アプリを閉じていても株価監視＆LINE通知を受け取れます。

セットアップ手順:
1. Cloudflareアカウントを作成（無料）
2. worker/ フォルダを wrangler deploy でデプロイ
3. LINE Notifyトークンを取得して設定
4. ここにWorker URLとトークンを入力
→ 詳細は worker/SETUP.md を参照
